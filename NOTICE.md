# Included components

Human Copilot includes tuikit.py, the author's shared Python curses toolkit,
and the Copilot Overlay GNOME extension. Python, GLib, GJS, GNOME Shell,
wl-clipboard, Zellij, Claude Code and Codex are external prerequisites or optional
integrations; their code is not bundled by this release.

This public release starts from a reviewed source snapshot with fresh Git
history. Private task records, user configuration, prompts, attachments,
credentials and the host's benchmark/keybinding inventories are excluded.
